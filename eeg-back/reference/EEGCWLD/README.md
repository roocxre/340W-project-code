# EEG Signal Analysis and Visualization Toolkit

A comprehensive Python toolkit for power spectral density computation, brain electrical activity mapping (BEAM), and correlation analysis across different cognitive workload conditions using EEG signal.


## Features

1. Power Spectral Density (PSD) Analysis

2. Brain Electrical Activity Mapping (BEAM)

3. Correlation Analysis

## 📦 Installation

1. **Clone or download the repository:**
```bash
git clone <your-repository-url>
cd eeg-analysis-toolkit
```

2. **Install required packages:**
```bash
pip install mne matplotlib numpy scipy pandas seaborn
```

3. **Verify installation:**
```python
import mne
import matplotlib.pyplot as plt
import numpy as np
print("All packages installed successfully!")
```
